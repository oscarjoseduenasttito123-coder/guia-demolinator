Conectar Autodesk Revit con IA mediante MCP y pyRevit

Aprende a instalar el puente local Demolinator para permitir que un asistente de IA audite metrados de concreto, cree vigas, columnas o muros desde un PDF y ejecute comandos en Revit.

¿Cómo funciona esta conexión? (Flujo de 4 capas)
1. Claude Desktop Envía comandos y procesa prompts
2. FastMCP (uv) Servidor local Python (stdio)
3. pyRevit Routes Microservidor HTTP (:48884)
4. Revit API Modela y extrae metrados
0
Prerrequisito Fundamental

Instalar pyRevit en tu computadora

Demolinator requiere que tengas pyRevit instalado para poder usar su motor de microservidor HTTP (Routes) dentro de Revit.

Si todavía no tienes la pestaña pyRevit en tu cinta de opciones de Revit:

Descargar instalador de pyRevit (.exe)
Verificación: Abre Revit y verifica que en el menú superior aparezca la pestaña morada o con el nombre pyRevit.
1
Entorno de Ejecución

Instalar el gestor de paquetes de Python (uv)

uv es un gestor de paquetes en Rust para Python de alta velocidad que Demolinator usa para descargar sus librerías sin ensuciar tu sistema.

Abre la consola de PowerShell y ejecuta este comando:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Comprueba que la instalación fue exitosa:

uv --version
¿Te salió el error rojo de comando no reconocido?

Eso pasa porque la ventana de PowerShell no había cargado la ruta en sus variables de entorno. Cierra esa ventana de PowerShell y abre una nueva, o pega este comando para recargar el PATH sin reiniciar: 

$env:Path = [System.Environment]::GetEnvironmentVariable("Path","User") + ";" + [System.Environment]::GetEnvironmentVariable("Path","Machine")
2
Herramienta de Clonación

Instalar Git para Windows

Git es el programa que te permitirá clonar y descargar el código oficial de Demolinator directamente desde GitHub hacia tu disco duro.

Si no tienes Git instalado en tu máquina, descárgalo e instálalo con las opciones predeterminadas:

Ir a descargar Git para Windows (64-bit Standalone)

Verifica en tu PowerShell que Git esté listo:

git --version

Debe devolver un texto similar a git version 2.4x.x.windows.1.

3
Descarga de la Extensión

Clonar el repositorio dentro de pyRevit

La extensión debe guardarse obligatoriamente en una carpeta con el sufijo .extension para que pyRevit la reconozca.

Ejecuta en PowerShell para entrar a la carpeta de pyRevit y clonar el proyecto:

cd "$env:APPDATA\pyRevit\Extensions"
git clone https://github.com/Demolinator/revit-mcp-server.git revit-mcp.extension

Ahora entra a la carpeta clonada e instala sus dependencias con uv sync:

cd "$env:APPDATA\pyRevit\Extensions\revit-mcp.extension"
uv sync
Verificación de estructura: Dentro de revit-mcp.extension debes ver directamente los archivos startup.py, main.py y la subcarpeta revit_mcp.
4
Configuración Interna en Revit

Vincular Carpeta y Encender el Servidor de Rutas

Este paso es el que evita los errores de ruta (RouteHandlerNotDefinedException) y los bloqueos en pantalla.

  1. Abre Autodesk Revit y carga cualquier proyecto (o una plantilla en blanco).
  2. En la cinta superior, ve a la pestaña pyRevit ➔ haz clic en la flechita chica debajo de pyRevit ➔ Settings.
  3. Baja hasta la sección "Directorios de Extensión Personalizados", haz clic en el botón Agregar carpeta y selecciona: C:\Users\TU_USUARIO\AppData\Roaming\pyRevit\Extensions *(Nota: Selecciona la carpeta Extensions, no entres dentro de revit-mcp.extension).*
  4. En el menú lateral de la misma ventana de Settings, haz clic en la sección Rutas y asegúrate de que el interruptor esté encendido: 🔘 Servidor de Rutas (Beta) → ACTIVADO (Azul)
  5. Haz clic en el botón "Solo Guardar Configuración". ⚠️ IMPORTANTE: Cierra Revit completamente y vuelve a abrirlo. (No uses "Guardar y Recargar" porque congela la interfaz de Revit).
5
Diagnóstico de Red Local

Comprobar que Revit responda en el navegador

Antes de configurar Claude, debemos validar que el microservidor local esté vivo y escuchando en el puerto 48884.

Con Revit y tu proyecto abierto, abre tu navegador y entra a este enlace:

http://localhost:48884/revit_mcp/status/
Si está bien configurado, verás una respuesta como esta: 
{
  "status": "active",
  "health": "healthy",
  "revit_available": true,
  "document_title": "tu_proyecto_abierto",
  "api_name": "revit_mcp"
}
6
Integración Final

Configurar claude_desktop_config.json

Configuraremos Claude Desktop para que reconozca tanto Nonica como Demolinator al mismo tiempo.

Presiona Win + R, pega la ruta %APPDATA%\Claude\claude_desktop_config.json y presiona Enter. Configura tu bloque mcpServers: 

{
  "mcpServers": {
    "Revit-Nonica": {
      "command": "C:\\NONICA\\OtherFiles\\System\\Core\\net8.0-windows\\RevitMCPConnection.exe",
      "args": []
    },
    "Revit-Demolinator": {
      "command": "C:\\Users\\USUARIO\\.local\\bin\\uv.exe",
      "args": [
        "--directory",
        "C:\\Users\\USUARIO\\AppData\\Roaming\\pyRevit\\Extensions\\revit-mcp.extension",
        "run",
        "main.py"
      ]
    }
  }
}

Recuerda cambiar USUARIO por el nombre de tu usuario de Windows.

Dinámica Práctica para la Clase

Usa esta secuencia para demostrar cómo la inteligencia artificial complementa la programación clásica de scripts:

Laboratorio 1: Contraste de Metrados

1. Ejecuta tu script personalizado en pyRevit para obtener el metrado de concreto.
2. En Claude Desktop pídele:

"Lista las columnas y vigas del modelo activo y calcula el volumen de concreto por sección."

Enseñanza: Compara la velocidad de un script rígido vs. la flexibilidad de consulta en lenguaje natural con MCP.

Laboratorio 2: Modelado desde PDF

1. Adjunta un plano de arquitectura o estructuras en PDF al chat de Claude.
2. Envía esta indicación:

"Lee las coordenadas y ejes de este plano y usa Demolinator para modelar los muros perimetrales en el Nivel 1."

Enseñanza: Los alumnos verán cómo la visión computacional del LLM genera elementos paramétricos nativos en Revit.
