Instalación y Conexión de Demolinator MCP

Habilita a Claude Desktop para modelar elementos estructurales, consultar geometría analítica y generar metrados en tiempo real mediante pyRevit Routes.

Flujo de Ejecución (Arquitectura del Taller)
Claude Desktop Prompt & Parámetros
MCP FastMCP (Python) uv run main.py (stdio)
pyRevit Routes HTTP localhost:48884
Revit API Engine Modelado & Metrados

Requisitos Previos Obligatorios

Autodesk Revit

Versión 2024, 2025, 2026 o 2027 instalada.

pyRevit CLI / Runtime

Instalado con pestaña funcional en Revit.

Claude Desktop

Cliente de Anthropic en Windows.

1
Entorno de ejecución

Instalar el gestor ultrarrápido de Python (uv)

Demolinator utiliza uv para resolver dependencias y levantar el servidor FastMCP sin alterar tu Python global.

Abre PowerShell como usuario regular y ejecuta:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
¿Te dio error de comando no reconocido al poner uv --version?

Cierra esa ventana de PowerShell y abre una nueva para que Windows cargue el nuevo Path. Comprueba con: 

uv --version
2
Clonación del Repositorio

Instalar la extensión en pyRevit

La extensión debe residir en la carpeta de extensiones de pyRevit para que el módulo registre los 48 endpoints de la API.

Ejecuta en PowerShell para ingresar a la carpeta de pyRevit y clonar:

cd "$env:APPDATA\pyRevit\Extensions"
git clone https://github.com/Demolinator/revit-mcp-server.git revit-mcp.extension

Instala las dependencias del servidor MCP con uv sync:

cd "$env:APPDATA\pyRevit\Extensions\revit-mcp.extension"
uv sync
3
Configuración de pyRevit

Vincular Carpeta y Encender Servidor de Rutas

Este paso evita el error de ruta no encontrada (RouteHandlerNotDefinedException) y los congelamientos de Revit.

  1. Abre Autodesk Revit y abre cualquier proyecto estructural o plantilla arquitectónica.
  2. En la cinta superior, dirígete a la pestaña pyRevit ➔ clic en la flecha de pyRevit ➔ Settings.
  3. En el apartado "Directorios de Extensión Personalizados" (abajo), haz clic en Agregar carpeta y selecciona: C:\Users\TU_USUARIO\AppData\Roaming\pyRevit\Extensions (Selecciona la carpeta padre Extensions, no la interior).
  4. En el panel izquierdo, ve a la sección Rutas y enciende el interruptor: 🔘 Servidor de Rutas (Beta) → ACTIVADO (Azul)
  5. Haz clic en "Solo Guardar Configuración". Cierra Revit completamente y vuelve a abrirlo (esto previene los cuelgues que genera la opción "Guardar y recargar").
4
Verificación de Endpoint

Comprobar Conexión Local en Navegador

Asegúrate de que pyRevit Routes esté respondiendo antes de enlazarlo con el cliente LLM.

Abre tu navegador e ingresa a:

http://localhost:48884/revit_mcp/status/
Respuesta Exitosa Esperada: 
{
  "status": "active",
  "health": "healthy",
  "revit_available": true,
  "document_title": "tu_proyecto_estructural",
  "api_name": "revit_mcp"
}
5
Integración Anthropic

Configurar Claude Desktop (claude_desktop_config.json)

Vincula Demolinator junto a Nonica MCP en el archivo central de configuración de Claude.

Abre tu archivo con Win + R ➔ ejecuta %APPDATA%\Claude\claude_desktop_config.json y configura ambos servidores: 

{
  "mcpServers": {
    "Revit-Nonica": {
      "command": "C:\\NONICA\\OtherFiles\\System\\Core\\net8.0-windows\\RevitMCPConnection.exe",
      "args": []
    },
    "Revit-Demolinator": {
      "command": "C:\\Users\\USUARIO\\.local\\bin\\uv.exe",
      "args": [
        "--directory",
        "C:\\Users\\USUARIO\\AppData\\Roaming\\pyRevit\\Extensions\\revit-mcp.extension",
        "run",
        "main.py"
      ]
    }
  }
}

Reemplaza USUARIO por el nombre exacto de tu cuenta de Windows.

Dinámica Didáctica de Clase

Casos de Uso para el Alumno en Laboratorio

Metodología de contrastación entre tu software previo en código directo vs. MCPs inteligentes.

Ejercicio 1: Auditoría de Metrados

Ejecuta tu botón de pyRevit tradicional que calcula volúmenes estructurales. Luego en Claude le pides:

"Audita el volumen total de concreto de columnas y vigas con Nonica y clasifícalo por tipo de sección."
Objetivo: Comparar volumen nominal ($b \times h \times L$) vs. volumen sólido neto (`Solid.Volume`).
Ejercicio 2: De Plano PDF a Modelo 3D

Arrastra el plano en PDF o imagen de distribución al chat de Claude Desktop y solicita:

"Analiza las cotas de este plano y usa Demolinator (create_line_based_element) para levantar los muros perimetrales en el Nivel 1."
Objetivo: Ver en vivo cómo Claude razona las coordenadas y crea geometría paramétrica en Revit.
