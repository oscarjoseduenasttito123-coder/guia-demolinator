Conexión de Modelos BIM con Model Context Protocol (MCP)

Protocolo estandarizado para vincular el motor de geometría de Autodesk Revit con Claude Desktop. Compara metrados paramétricos automatizados frente a agentes de generación geométrica por planos.

1
Paso 01 • Entorno de Ejecución

Instalar el Gestor Astral UV (Python)

uv resuelve e instala las dependencias de Demolinator a alta velocidad sin ensuciar tu instalación principal de Python.

Abre PowerShell y pega el comando de instalación: 
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
Comprobación obligatoria: Cierra esa consola de PowerShell y abre una nueva. Luego escribe uv --version para verificar que responda con la versión instalada (ej: uv 0.12.x).
2
Paso 02 • pyRevit Extensions

Clonar el Servidor Demolinator

Demolinator se integra como una extensión nativa para que pyRevit exponga sus herramientas al protocolo MCP.

Ejecuta en PowerShell para entrar a la carpeta de pyRevit y clonar el repositorio: 
cd "$env:APPDATA\pyRevit\Extensions"


git clone https://github.com/Demolinator/revit-mcp-server.git revit-mcp.extension

    2.

            C:\Users\TU_USUARIO\AppData\Roaming\pyRevit\Extensions

      Paso 05 • Cliente Claude
      
Configurar Claude Desktop (Configuración Dual)

      

        Esta configuración te permite tener Nonica MCP (para auditoría y lectura rápida) y Demolinator MCP (para creación paramétrica 3D) en un solo archivo.
      

    


    

      
        Abre tu archivo con Win + R ➔ pega %APPDATA%\Claude\claude_desktop_config.json y usa este bloque:
      
      

        
{


"mcpServers": {
"Revit-Nonica": {
"command": "C:\NONICA\OtherFiles\System\Core\net8.0-windows\RevitMCPConnection.exe",
"args": []
},
"Revit-Demolinator": {
"command": "C:\Users\USUARIO\.local\bin\uv.exe",
"args": [
"--directory",
"C:\Users\USUARIO\AppData\Roaming\pyRevit\Extensions\revit-mcp.extension",
"run",
"main.py"
]
}
}
}

 Copiar



 Recuerda reemplazar USUARIO por el nombre exacto de tu cuenta de Windows en ambas rutas.

           Ejercicio A: Comparativa de Metrados
        
        

          1. Ejecuta tu botón de pyRevit tradicional para calcular volúmenes de concreto.

          2. En Claude Desktop con el servidor Nonica activo, escribe:
        

        

          "Audita el volumen de concreto de las columnas y vigas en el modelo actual y agrúpalo por tipo de elemento."
        

        

          Análisis en clase: Comparar el volumen nominal ($b \times h \times L$) vs. volumen sólido neto descontando uniones geométricas (`Solid.Volume`).
        

      


      
      

        
           Ejercicio B: De Plano PDF a Modelo 3D
        
        

          1. Arrastra una imagen o plano PDF de planta al chat de Claude Desktop.

          2. Con el servidor Demolinator activo, escribe:
        

        

          "Identifica las cotas y ejes de este plano y utiliza las herramientas de Demolinator para crear los muros perimetrales en el Nivel 1 de Revit."
        

        

          Análisis en clase: Demostrar cómo el LLM interpreta geometría 2D y llama a create_line_based_element en tiempo real.
