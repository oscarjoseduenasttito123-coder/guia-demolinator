1
Paso 01

Instalar el Gestor Astral UV en Windows

Abre PowerShell y ejecuta el comando de instalación oficial:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Una vez instalado, cierra PowerShell y vuelve a abrirlo para verificar con uv --version.

2
Paso 02

Clonar la Extensión en la carpeta de pyRevit

Ejecuta las siguientes dos líneas en PowerShell:

cd "$env:APPDATA\pyRevit\Extensions"


git clone https://github.com/Demolinator/revit-mcp-server.git revit-mcp.extension

 Copiar



  
Instala los entornos virtuales y paquetes internos con:

  

    
cd "$env:APPDATA\pyRevit\Extensions\revit-mcp.extension"


uv sync

 Copiar







  

    3
  

  

    Paso 03
    
Configurar Rutas y Extensiones en pyRevit

    
Abre Revit y dirígete al menú de configuración:

  


  

    
    
      
  • Pestaña pyRevit ➔ Desplegable pyRevit ➔ Settings.
    • 
      
  • En "Directorios de Extensión Personalizados", haz clic en Agregar carpeta y selecciona:
        C:\Users\TU_USUARIO\AppData\Roaming\pyRevit\Extensions
      
    • 
      
  • En la barra lateral izquierda ve a Rutas y enciende el interruptor: "Servidor de Rutas (Beta)".
    • 
      
  • Haz clic en Solo Guardar Configuración.
    • 
      
  • Importante: Cierra Revit completamente y vuelve a abrirlo (no uses "Guardar y recargar" para evitar cierres inesperados).
    • 
    

  







  

    4
  

  

    Paso 04
    
Comprobar Servidor Local de Revit

    
Con Revit y tu proyecto abierto, entra al navegador en:

  


  

    
      http://localhost:48884/revit_mcp/status/
      
    
  

  

     Debe responder con "revit_available": true y el nombre de tu proyecto.
  







  

    5
  

  

    Paso 05
    
Enlazar con Claude Desktop (Configuración Dual)

    

      Presiona Win + R, escribe %APPDATA%\Claude\claude_desktop_config.json y reemplaza su bloque con este archivo que activa Nonica y Demolinator:
    

  


  

    
{


"mcpServers": {
"Revit-Nonica": {
"command": "C:\NONICA\OtherFiles\System\Core\net8.0-windows\RevitMCPConnection.exe",
"args": []
},
"Revit-Demolinator": {
"command": "C:\Users\USUARIO\.local\bin\uv.exe",
"args": [
"--directory",
"C:\Users\USUARIO\AppData\Roaming\pyRevit\Extensions\revit-mcp.extension",
"run",
"main.py"
]
}
}
}

 Copiar



 Recuerda cambiar USUARIO por el nombre de tu usuario de Windows.
